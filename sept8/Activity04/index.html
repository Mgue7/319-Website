ReelRank

ReelRank was the first project I created and was a fishing leaderboard app that I made using a React frontend and FastAPI backend, I hosted the app on Vercel and used Supabase as the database in order to store users, catch data, and images. Users could input their catches and have them be ranked against other users, with their being different leaderboards for different fish species.
